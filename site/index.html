Principaux résultats

Détection du défautSpectre d'enveloppe : défaut de bague extérieure identifié 74 h avant la rupture, aucune fausse détection en phase saine (984 acquisitions du 2nd essai).
Durée de vie résiduelleCNN-LSTM évalué sur un roulement jamais vu (validation croisée sur 4 pannes) : erreur moyenne ≈ 0,9 j pendant la dégradation, contre 1,4 j pour une prédiction constante.
Classification healthy / faultyF1 ≈ 0,99 en validation croisée classique ; ≈ 0,6 sur un roulement jamais vu (section 6.3 du notebook).
DonnéesNASA Prognostics Data Repository — IMS Bearing Dataset (University of Cincinnati), 3 essais jusqu'à la rupture, 20 kHz.

Ouvrir le projet dans VS Code

  1. Télécharger l'archive puis l'extraire (clic droit → « Extraire tout »).
  2. Dans VS Code : Fichier → Ouvrir le dossier, puis choisir le dossier pfa_maintenance_roulements.
  3. Installer les bibliothèques dans un terminal : pip install pandas numpy scipy matplotlib seaborn scikit-learn PyWavelets xgboost tensorflow
  4. Ouvrir IMS_Bearing_Analysis_corrige.ipynb : les résultats sont déjà enregistrés, la réexécution utilise le dossier cache/ (pas besoin des 6 Go de données brutes).
  5. Le fichier README.md décrit chaque fichier et la façon de régénérer les interfaces.
Les calculs des interfaces sont exécutés dans le navigateur ; aucune donnée importée n'est transmise.
